# Movie & Series Finder (Telegram bot)

Type any movie/web series name -> rating, story, cast, trailer and which OTT app streams it in India.
/new (new OTT releases by language), /trending, /watchlist, Stars tips.
Data: TMDB API; streaming availability by JustWatch. This product uses the TMDB API but is not endorsed or certified by TMDB.

Env: BOT_TOKEN, TMDB_TOKEN (v4 read token), DATABASE_URL (Postgres, optional), WEBHOOK_URL (optional).
